# Design decisions
The requested recommended decisions are adopted without an interview. Scope: six original puzzles in a Hearty Heroes-inspired slice, teaching push, mandatory pull, ranged swap and cooperation. A fixed elevated board, readable silhouettes, original names and art, unrestricted level selection, unlimited undo and restart. The pure transition function is the test seam; authored solutions prove every puzzle reachable. Browser acceptance uses ordinary keyboard and visible buttons. No changes to other games or browser saves.

All heroes must occupy exits simultaneously. No timer or lives. A blocked action is a no-op, while a misplaced crystal can create a recoverable deadlock. Switching selects an existing hero; it never changes a hero's ability. Wizards swap with heroes as well as crystals in this kata. Original game's exact keybindings and all cross-object edge cases remain unverified. No cross-world mirrors, beams, throwing, monsters or later classes are claimed.
